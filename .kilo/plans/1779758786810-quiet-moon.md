# Plan: rsnano-work Head-to-Head Benchmark

## Goal
Create an experimental branch that brings the **rsnano-node work generator crate** into this project as a standalone crate, then wires it into the CLI benchmark so all backends — CPU, wgpu (ours), OpenCL (ours), **rsnano CPU, rsnano OpenCL** — race head-to-head.

## Branch
`experiment/rsnano-head-to-head`

---

## 1. New Crate: `nano-rspow-rsnano/`

A self-contained Rust crate adapted from [rsnano-node's `work` crate](https://github.com/rsnano-node/rsnano-node/tree/develop/work), stripped of `rsnano_types` and `rsnano_utils` dependencies, using raw `[u8; 32]` / `u64` types and a standalone difficulty function.

### 1a. `Cargo.toml`

```toml
[package]
name = "nano-rspow-rsnano"
version.workspace = true
edition.workspace = true
license.workspace = true

[features]
default = []
opencl = ["dep:ocl"]

[dependencies]
blake2b_simd = "1"
rand = "0.9"
ocl = { version = "0.19", optional = true }
```

No dependency on nano-rspow — fully standalone. Uses the same `blake2b_simd` crate as nano-rspow.

### 1b. Source files

| File | Purpose |
|------|---------|
| `xorshift.rs` | Identical XorShift1024Star RNG (same algorithm as ours but seeded via `rand::rng()`) |
| `difficulty.rs` | Standalone `compute(hash, nonce) -> u64` (identical to nano-rspow's) |
| `cpu_work_generator.rs` | `CpuWorkGenerator` — single-threaded batch iteration (256 attempts/batch) with optional rate limiter |
| `work_ticket.rs` | `WorkTicket` — atomic-counter-based expiration for cancelling in-progress work |
| `work_queue.rs` | `WorkQueueCoordinator` + `WorkQueue` — thread-safe FIFO with Condvar notification |
| `work_thread.rs` | `WorkThread` — pulls work items from queue, runs `CpuWorkGenerator.create()`, notifies completion |
| `work_pool.rs` | `WorkPool` — spawns N CPU threads (+ optional GPU thread), wires up WorkQueueCoordinator |
| `gpu.rs` | Raw OpenCL bindings (`Gpu` struct) — adapted from rsnano, `#[cfg(feature = "opencl")]` |
| `gpu_work_generator.rs` | `GpuWorkGenerator` — wraps `Gpu` with `XorShift1024Star`, `#[cfg(feature = "opencl")]` |
| `work.cl` | OpenCL kernel — verbatim from rsnano (hand-optimized Blake2b rounds, AMD media ops) |
| `lib.rs` | Public API: `WorkPool::builder().cpu_threads(n).enable_gpu(bool).finish()`, `pool.generate(hash, threshold) -> Option<u64>` |

### 1c. API surface (lib.rs)

```rust
/// Main work pool — spawns threads on construction, cleans up on drop.
pub struct WorkPool { ... }

pub struct WorkPoolBuilder { ... }

impl WorkPoolBuilder {
    pub fn cpu_threads(self, n: usize) -> Self;
    pub fn enable_gpu(self, enable: bool) -> Self;       // requires opencl feature
    pub fn gpu_only(self) -> Self;
    pub fn cpu_only(self) -> Self;
    pub fn one_cpu_only(self) -> Self;
    pub fn cpu_rate_limit(self, d: Duration) -> Self;
    pub fn finish(self) -> WorkPool;
}

impl WorkPool {
    pub fn builder() -> WorkPoolBuilder;

    /// Generate work for a 32-byte hash at the given difficulty threshold.
    /// Blocks until a valid nonce is found or cancellation.
    pub fn generate(&self, hash: &[u8; 32], threshold: u64) -> Option<u64>;

    /// Cancel in-progress work for a specific hash.
    pub fn cancel(&self, hash: &[u8; 32]);

    pub fn has_opencl(&self) -> bool;
    pub fn thread_count(&self) -> usize;
}
```

### 1d. Key adaptation decisions

| rsnano concept | Adapted to |
|---------------|-----------|
| `Root` (`[u8; 32]` newtype) | `[u8; 32]` directly |
| `WorkNonce` (`u64` newtype) | `u64` directly |
| `Difficulty` / `DifficultyV1` trait | Free function `difficulty::compute()` |
| `WorkRequest` / `WorkRequestAsync` with callbacks | Simplified to a oneshot channel per request |
| `WorkThresholds` (full/beta/dev/test) | Removed — caller passes threshold directly |
| `tracing` crate | Removed — no logging in benchmark context |
| `rsnano_utils::ContainerInfo` | Removed — not needed |
| `rand = "0.10"` | `rand = "0.9"` (matches workspace) |

### 1e. WorkPool thread model

1. **Construction**: `finish()` creates `WorkQueueCoordinator` (shared Arc), spawns N CPU threads + optional GPU thread
2. **CPU thread**: `WorkThread<CpuWorkGenerator>` runs a loop: lock queue → get front item → drop lock → generate in batch → re-lock → notify result
3. **GPU thread**: `WorkThread<GpuWorkGenerator>` — same pattern, but generates via OpenCL
4. **Cancellation**: `WorkTicket` (atomic counter) — when work is found by any thread, the ticket counter increments, causing all other threads' tickets to expire on next check
5. **Drop**: `pool.stop()` signals all threads to exit, then joins them

## 5. Notes & Caveats

- **rsnano CPU** uses `std::thread` per core (not rayon). This is a key architectural difference from our `cpu` backend which uses rayon's work-stealing pool. The benchmark will reveal which thread model is more efficient for PoW.
- **rsnano OpenCL** uses a different kernel (`work.cl` — hand-optimized Blake2b with 12 rounds) than our `opencl` backend (`pow.cl` — simpler Blake2b). Another dimension of comparison.
- **rsnano RNG** is initialized from system entropy (`rand::rng()`) vs our seeded RNG — this has no performance impact but means different nonce search paths.
- **Rate limiter is disabled** (`Duration::ZERO`) during benchmarking — we want max throughput.
